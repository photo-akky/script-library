# script-library

個人的なスクリプト集です。

日々の作業を少し楽にするための Python スクリプトや、Docker コンテナの定義・設定ファイルなどを格納します。

用途に応じて、使い方や実行環境、必要な設定もあわせて記録していきます。

## スクリプト

- [インターバル撮影の写真分類](scripts/interval_photos/README.md)：Mac のファイル作成日時から撮影セットを抽出し、JPG と RAW をまとめて移動します。[NAS 向け Web GUI](scripts/interval_photos/WEB_README.md) は Exif による候補確認に対応します。
